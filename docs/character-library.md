# キャラクター一覧・名前変更・削除・コピー仕様

## 画面遷移

1. メインメニューで「キャラクターを作る」を選ぶ。
2. キャラクター一覧を表示する。初回は空の一覧と「新規キャラクター」を表示し、勝手に作成画面へ進めない。
3. 各作品の「続きから編集」で、その保存IDの画像を復元して編集する。
4. 「新規キャラクター」で名前・サイズの作成画面へ進む。「描き始める」で別IDの作品を保存して編集する。
5. 作成画面・編集画面からは一覧へ戻る。一覧からメインメニューへ戻れる。

一覧には名前・種類・サイズ・更新日時を表示する。以前の分類なし画像も一覧に残して引き継ぐ。固定の保存件数制限は設けず、端末の保存容量を上限とする。

## 名前の変更

- 各作品の「名前を変更」で、現在の名前を選択済みの入力欄に表示する。
- 前後の空白を除いた1〜40文字を受け付ける。空の名前は保存せず、入力エラーを表示する。同じ名前の別作品も許可する。
- 「変更を保存」で指定IDの名前と更新日時だけを端末に保存する。ID・種類・寸法・全12コマのRGBA・編集中のコマ・他の作品・パレット・コピー済みの控えは変更しない。
- 待機中の自動保存を先に完了し、同じトランザクションで保存レコードを読み直して名前だけ更新する。古い画素での上書きや、遅れた自動保存で名前が戻ることを防ぐ。
- 保存成功後に一覧と編集中の作品名を更新する。描画の履歴を保持し、Undo / Redoで新しい名前を維持する。名前変更自体は描画のUndoに含めない。
- キャンセル・Escapeでは変更しない。保存中は二重操作と閉じる操作を止める。失敗時は元の名前と作品を保持し、ダイアログから再試行・キャンセルできる。
- GitHub同期を設定している場合は、新しい名前も同期する。入力中に自動同期やPWAの更新でダイアログを中断しない。

## 削除

- 各作品の「削除」で、その作品名を表示した確認ダイアログを開く。
- 「キャンセル」および処理前の閉じる操作ではデータを変えない。
- 「削除する」で選んだIDだけを削除し、保存処理の完了後に一覧から除く。処理中は二重操作・ダイアログを閉じる操作を止める。
- 削除はUndo対象外。他の作品・共有パレット・コピーしたデータは消さない。
- 削除前に編集中の保存と待機中の書き込みを完了させる。現在編集中だった作品を削除した場合は、その編集状態もクリアし、遅れた自動保存による復活を防ぐ。
- 旧単一枠から移行した作品は、確認済みの削除時に元のバックアップも同じトランザクションで削除する。移行済みマーカーは残し、再起動で復活させない。
- 失敗時はダイアログを閉じず、エラーと再試行・キャンセル手段を表示する。削除に成功するまでは一覧から除かない。

## コピーと貼り付け

- 作品単位のアプリ内コピー。OSのクリップボードや他アプリへの貼り付けではない。
- 各作品の「コピー」で、保存済みの名前・サイズ・12コマのRGBA画素・編集中のコマをコピー用の領域へ保存する。編集中の画像は先に保存してからコピーする。
- コピーは1件分で、次にコピーするまで保持する。再起動・オフライン起動でも復元する。コピー元を後から編集・削除してもコピーは変えない。
- 一覧の「貼り付けて新規作成」で、新しいIDと「元の名前のコピー」という名前のキャラクターを保存して編集を始める。繰り返し貼り付けても上書きしない。
- サイズ・透明度・全画素を保持する。画像配列は独立させ、貼り付け先を編集しても元の作品やコピーに影響させない。
- Undo履歴・ツール設定・表示用の補助線は複製しない。色パレットは全作品共通なので別途コピーしない。
- 未コピー時は貼り付けを無効にする。コピー失敗時は直前のコピーを保持する。貼り付け失敗時は一覧に未保存作品を追加しない。

## 検証

実ブラウザで、一覧優先の遷移、独立した貼り付け先、画素・透明度・寸法、削除キャンセル、削除後の再起動、元作品削除後のオフライン貼り付け、保存・削除・コピー失敗時の保持、待機中の保存と削除の順序を確認する。iOS Safariの実機で、タップ領域・確認ダイアログ・ホーム画面起動も確認する。

## キャラクターの12コマ

1作品に同じ寸法の12枚を保持する。列は左足・直立・右足、行は正面・左向き・右向き・後ろ。編集画面は1枚を表示し、上下で向き、左右でポーズを切り替える。12コマ一覧からも直接選択できる。PNGはこの並びの3列×4行、余白なし、透明背景で出力する。32×32なら96×128になる。

「1コマ全体コピー」はそのコマのRGBA全体を独立して保持する。「1コマ全体貼り付け」は同じ寸法の現在のコマだけを透明部分も含めて置き換え、Undo1回で戻せる。サイズ不一致・未コピー・描画中・範囲貼り付け中は貼り付け不可。クリップボードは起動中だけ保持し、範囲コピーと作品コピーとは独立する。

既存の1枚のキャラクターは正面・直立に引き継ぎ、他の11枚は透明。分類なしの旧画像はそのまま。保存レコードv2は全12枚・編集中のコマを検証し、不正なデータは保持して警告する（IndexedDB自体のバージョンは2のまま）。
